# README #
Welcome to the data repository for our paper. Below, you will find information about the dataset, including its structure, contents, and guidelines for use. 

### Dataset Overview ###
This dataset contains Temperature-Programmed Desorption data corresponding to the series of experiments described in Table 2 of our accompanying paper. The focus of these experiments is to explore the thermal desorption of various molecular ice mixtures under specific conditions.

### File Structure ###
The data is organised into .csv files named according to the experiment number and the molecules involved in the experiment. Each file represents the data from one experiment as detailed in Table 2 of the paper.

Example
- File Name: 10_binary_CO.csv
- Description: Data for Experiment 10 from Table 2; a binary mixture analysis of H2O and CO.
- Details: Ratio 2:1 (H2O:CO), 6.55 ML of H2O, 3.7 ML of CO, total coverage of 10.25 ML, deposited at 10 K, heating rate of 0.2 K/s.

- Desorption rates are in monolayers per Kelvin (ML/K) and Temperature is in Kelvin. 
- The only exception is for Exp. 23 (file name: 23_binary_CO_beta_0.02K/s_ML/s) where the desorption rate is expressed in monolayers per second (ML/s) versus time in seconds (s).

### File format ###

- Format: Comma-Separated Values (.csv)
- Delimiter: Semicolon (;)
- Decimal: Dot (.)
