# Checkpoint evidence ledger

Updated 22 October 2026. Owner: Karol Cieślik (maintainer); implementation and automated review assisted by Codex. No independent human reviewer sign-off is claimed.

**Done** means the specific implementation/documentation checkpoint is supported by the listed evidence. **Partial** means work exists but the full acceptance criterion is not met. **Open** means remaining work. **External/release dependency** requires experimental data, human observation/review, sustained use or an accepted release; it is not marked complete by automated tests.
